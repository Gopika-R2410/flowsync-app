## 🌈 the vibe

> Task apps are boring. FlowSync isn't. It's the productivity dashboard that actually makes you *want* to lock in — priority tags, focus timers, streak flexing, all wrapped in a UI that doesn't look like it's from 2013.

<br>

## 🔥 what it does

<table>
<tr>
<td width="50%" valign="top">

### 📝 Task Management
Add tasks with **priority levels**, **categories**, and **due dates**. No more sticky notes falling off your monitor.

### ⏱️ Pomodoro Timer
Built-in focus sessions to help you actually finish the thing instead of reorganizing your desktop for the 5th time.

</td>
<td width="50%" valign="top">

### 📊 Progress Tracking
Visual receipts of what you actually got done today (proof you're not just "busy" busy).

### 🔥 Streak Counter
Gamified consistency tracking — because nothing hits like a 30-day streak you refuse to break.

</td>
</tr>
</table>

## 🚀 how to use it

```
1️⃣  Add a task  →  set priority + category
2️⃣  Slap on a due date so future-you can't dodge it
3️⃣  Hit the Pomodoro timer  →  lock in
4️⃣  Watch your progress bar (and streak 🔥) go up
```
